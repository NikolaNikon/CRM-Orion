# Чистопар

Внутреннее приложение Twenty для CRM банных комплексов. Первый этап охватывает карточку комплекса, разряды, залы, тарифы, услуги, гостей, заявки, блокировки времени и дневную «шахматку» бронирований.

## Границы первого этапа

В этот модуль пока не входят публичный виджет бронирования, платежи, Telegram/MAX, Bitrix24, iiko и мобильное приложение. Он создаёт устойчивую предметную модель и операционный интерфейс, на которые эти каналы будут опираться позже.

## Запуск в среде разработки

```bash
yarn twenty remote:add --api-url http://localhost:2020 --as local
yarn twenty dev
```

После синхронизации приложение доступно в CRM в разделе `/settings/applications`.

## Структура

- `src/objects` — предметные объекты и их поля.
- `src/views` — стандартные списки и представления.
- `src/navigation-menu-items` — разделы меню CRM.
- `src/components` — custom frontend-компоненты, включая «шахматку».
- `src/logic-functions` — правила бронирования и доступности.
